# Site da ABTE

Site e painel da ABTE, Associação Brasileira de Tratamento da Escoliose, em Next.js e Firebase.

Toda a documentação do projeto (stack, comandos, arquitetura, etapas e regras) está em [CLAUDE.md](CLAUDE.md).

Para rodar localmente:

1. `npm install`
2. Copie `.env.example` para `.env.local` e preencha (veja as instruções no próprio arquivo).
3. `npm run dev` e abra http://localhost:3000
